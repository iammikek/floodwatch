Do

  • Cluster or density-cap markers; show counts not 200 popups
  • Viewport fetch only; debounce moveend
  • Polygons as light fills; detail on select
  • Layer presets (Dispatch / Hydrology) over many toggles

Don’t

  • Bind rich HTML popups to every marker
  • Re-create the whole map on Livewire morph
  • Stack warnings + zones + all gauges + incidents at once by default
  • Put primary copy only inside map chrome

Stack note (for later spike)

  1. Livewire is fine for forms/search/auth; painful when the map must survive frequent DOM morphs.
  2. Vue (or Inertia+Vue) island for the cockpit map + inspector keeps Leaflet owned by one client tree — better scale for pan/layer/select.
  3. Laravel stays API/session owner; lake stays data plane. No need to rewrite the whole app to validate this.
